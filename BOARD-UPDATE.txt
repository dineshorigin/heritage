PALLANGUZHI v3.19.0 — HOME, TOSS, SOWING & ROOM PAUSES

1. Mode labels centred on all home cards, including the wide mobile Connect card.
2. Small previous-step arrow with accessible label, kept on steps 2/3. System Back also returns to the previous setup step.
3/4. Manual first-player/P1/P2/alternate options removed. Every mode and fresh round uses a toss. Player 1 chooses Heads or Tails (Heads is the default and can be changed); in room mode the host chooses, guest receives the opposite side. The random winner is mapped to the correct visible coin face and sent to both clients. The existing short coin animation precedes play. The call participates in room Ready signatures.
5. Drop/capture motion now follows a monotonic accelerating path from release point to pit. Depth is represented by slight scale/shadow changes rather than an additional screen-axis arc. No spatial overshoot/return leg. Landing settle is a subpixel damped motion, not a second drop. Contact positions/seed rules remain authoritative separately.
6. Timer is a small numeric circle beside the name strip, shown only for a human choosing a cup in a timed game. Hidden while paused, sowing, tossing, finished or untimed. Accessible label describes seconds remaining.
7. Removed the added ivory edge marker beside the right elephant. Original artwork and black pupils remain.
8. New lightweight heritage room background used on home and all three settings steps, with dark/light readability overlays. 33,656-byte WebP, no idle animation. See BACKGROUND-NOTES.txt.
9. Opening Tools holds gameplay and decision clock. In-flight WAAPI animations pause; the sowing loop waits between events; Resume continues it without dropping or counting another seed. Closing Tools resumes if it created the pause, after any settings/replay/help panel closes. Existing explicit pauses are not accidentally resumed. Hint/Undo requested through a paused Tools menu resume first before applying the turn action. Native Finish Move is disabled during pause.
10. Room pause budget: two pauses per player per match, each at most 90 seconds. Tools, Pause and lifecycle pause requests use the same budget. Host validates/owns the budget; request IDs prevent duplicate consumption or extension. Only the pause owner can resume early. Both clients show owner, remaining time and local allowance. On expiry, room pause ends and menus close. Used allowance is retained across stable recovery/Undo; a separate pause-budget checkpoint also covers mid-sowing requests. New matches/rematches reset the budget, new Kasie rounds do not. Opening Tools while already paused does not consume another pause or extend it. After both pauses are used, Tools cannot initiate another pause; the Leave dialog can still return to the menu while the clock runs. Connection stalls are separate from user pauses.
11. Room chat is now a speech-bubble button in the bottom-right gameplay corner with unread count. Removed from the Tools sub-menu. Messaging itself does not automatically pause an online match.
12. Interpreted request as moving Daily Puzzle to HOME ONLY: a prominent gold puzzle/board icon card on the first home step. Removed its entry from Tools > Play & learn. Replays, guided learning and install help remain in that menu.

VALIDATION
63 automated tests passed: existing game/recovery/clock/replay/chat tests plus room pause limits, duplicate requests, owner-only resume, exact 90-second expiry, pause restoration, coin-face/winner mapping and monotonic travel for positive/negative displacements. Balanced HTML, unique IDs, literal element references, assets/module imports and JS syntax passed. Android source sync passed; no APK built. Archive integrity passed. Game rules are unchanged; prior 800-match engine simulation evidence remains historical.

LIMITS
New browser layout, real mid-animation pause/resume, touch motion, background appearance and two-device pause/toss networking are NOT browser/device-verified. Automatic approval review previously rejected browser inspection because of the session usage limit; no alternate browser was used to bypass it. Use MANUAL-CHECKS.txt. Host/client pause and decision clocks are friendly-room controls, not server-authoritative anti-cheat. Browser/OS suspension or a disconnected host can delay actual network/game continuation; a backend would be needed for competitive enforcement. No full release certification, GitHub commit or live deployment is claimed.
